Each option trades image detail or processing effort for a smaller file.

Images are processed by this site's image engine in temporary memory and are not stored. Supported formats retain their original format and dimensions; GIF animation and transparency are preserved when the source and encoder support them. Metadata is retained where the format and encoder permit it. BMP and ICO are not supported by the current image engine.
