Central advertising

Running Ads

Each unit has its own draft and published configuration. Saving a draft never changes the live code.

Every catalog unit is live across the site. Banners and Native Banner run in separate placement frames so each unit keeps its own provider globals. Every eligible action button opens the real provider destination in a new tab on every click: a Pop Under value that is an http(s) URL is used first, otherwise the published Smart Link URL is used. A script-only Pop Under snippet cannot fill an empty tab, so it is never used as a placeholder; publish the Smart Link URL for direct button delivery. The ad opens after the button's own action, so file pickers and downloads still work, and the original action still runs if the tab is blocked. Social Bar is injected once per page, and a Smart Link URL also becomes a labelled sponsored link. Saving and publishing a unit updates every placement that uses it. No ad is loaded into admin screens.
